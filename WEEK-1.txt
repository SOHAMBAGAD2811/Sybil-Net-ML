Product Requirements Document (PRD)
Sybil-Net
Week 1 – Graph Data Pipeline & Network Topology Foundation

Project: Sybil-Net – Graph Neural Network Based Decentralized Reputation Protocol

Sprint: Week 1

Duration: 7 Days

Objective

Establish the complete data foundation required for Graph Neural Network training by collecting blockchain transaction data, transforming it into graph structures, engineering initial graph features, and building visualization tools for inspecting the network.

At the end of Week 1, the project should be capable of converting raw blockchain transactions into a graph that represents wallet interactions and allows exploratory analysis of potential Sybil clusters.

1. Problem Statement

Traditional bot detection relies heavily on text analysis or behavioral heuristics, which are increasingly ineffective against modern AI-generated activity.

Instead of analyzing user-generated content, Sybil-Net identifies malicious actors through blockchain interaction topology.

The first step toward achieving this is creating an accurate representation of blockchain activity as a graph.

2. Week 1 Goals

By the end of Week 1 the system should:

Fetch blockchain transaction data
Convert transactions into graph structures
Store graph efficiently
Compute basic graph statistics
Visualize wallet interactions
Prepare datasets for GNN training

No machine learning model will be trained this week.

8. User Stories

As a researcher,

I want to download blockchain transactions,

so that I can analyze wallet interactions.

I want blockchain data converted into graphs,

so that I can train a Graph Neural Network later.

so that model training becomes straightforward.
